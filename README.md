# TIC-TAC-TOE-PROJECT
## Description
A simple, interactive Tic-Tac-Toe game built using Python. This project was developed to practice fundamental programming concepts such as loops, conditional logic, and functions.

## Features
Two-player mode: Play against a friend locally.

Input Validation: Ensures players can only choose empty spots on the grid.

Win/Draw Detection: Automatically identifies when a player has won or if the game ends in a tie.

## Tech Stack
Language: Python

## Tools: VS Code, Git/GitHub

## How to Run
Ensure you have Python installed on your system.

# Clone this repository:


git clone https://github.com/aarushi0618/TIC-TAC-TOE-PROJECT.git
# Run the script:


python tic.py
